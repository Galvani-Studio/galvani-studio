# Galvani Studio

A Galvani Studio desenvolve sites institucionais, landing pages e sistemas web sob medida. Unimos design e tecnologia para criar uma presença digital clara e profissional para empresas.

**Linguagens:** TypeScript, HTML e CSS.

**Tecnologias do site:** React, Next.js 15, Tailwind CSS e Framer Motion. O formulário utiliza Zod para validação, salva solicitações no banco MariaDB do WordPress e envia notificações por SMTP.

**Banco, painel e e-mail:** veja [o guia de configuração](wordpress/README.md). O ambiente local captura e-mails no Mailpit; a entrega real exige configurar um provedor SMTP.
